# Plovdiv Display

`PlovdivDisplay-Regular.woff2` and `PlovdivDisplay-Bold.woff2` are the official
Plovdiv Display webfonts by PUNKT and Typedepot (Plovdiv, Bulgaria, 2019).

The type family was released for free public use as part of the official
Plovdiv — European Capital of Culture 2019 programme. Project information,
downloads, and the current licence package are available at
<https://plovdivtypeface.com/en>.
